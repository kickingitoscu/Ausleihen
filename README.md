School Library Management System

Eine benutzerfreundliche, leichtgewichtige und mandantenfähige Schulbibliotheks-Verwaltungssoftware, die speziell für den unkomplizierten Einsatz durch nicht-technisches Personal entwickelt wurde. Das System läuft containerisiert und bietet eine komfortable One-Click-Bedienung unter Windows.

🚀 Hauptmerkmale
Intuitive Benutzeroberfläche: Entwickelt mit Streamlit für eine moderne, schnelle und selbsterklärende Bedienung ohne Schulungsaufwand.

Robuste Datenhaltung: Zuverlässige und strukturierte Speicherung aller Bestände, Ausleihen und Benutzerdaten über eine normalisierte SQLite-Datenbank.

Containerisierte Architektur: Vollständig gekapselt mittels Docker für eine plattformunabhängige, saubere Ausführung.

Windows- & WSL2-optimiert: Nahtlose Integration in Windows-Umgebungen über das Windows Subsystem for Linux (WSL2) inklusive eines automatisierten Desktop-Launchers (.bat), der Docker im Hintergrund startet und die Anwendung direkt im Browser öffnet.

Wartungsarm: Konzipiert für den produktiven Dauereinsatz in Schulen mit minimalem Administrationsaufwand.

🛠️ Technologie-Stack
Backend & Frontend: Python 3.12, Streamlit

Datenbank: SQLite

Containerisierung: Docker, Docker Compose

Umgebung: Linux (WSL2-Backend unter Windows)
